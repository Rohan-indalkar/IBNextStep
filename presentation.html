Project Analysis

Current System Limitations

⚠️

Single Tenant Setup

Configured for single institute deployments; multi-tenancy support requires organization ID scoping.

⚠️

Offline Compiler Limits

Live coding assessments evaluate code via backend API rather than a dedicated isolated sandbox sandbox.

⚠️

Email Dispatch Service

OTP codes are logged & transmitted in-app; external SMTP mail server integration is optional.
